# Issues that belong to core

Issues found while checking the pack against RGAA 4.1.2 whose cause is in core, so the pack cannot settle them through its map or its own rules. They are collected here to be reviewed together, and are not fixed in core from this branch.

The pack builds against core's main branch (after 1.13.1), which carries the fixes for every other issue listed here before: C1 to C4, C6 to C10, T1-04, T1-11, T13-02, T13-05, T13-08, T25-13 to T25-16, T67-07, T89-03, T89-04, T89-09, T89-10 and T12-11 are fixed in core or settled by the pack with what core now gives it (reason codes, the contrast settings, `animationsAtScanStart`, `styleSheetTexts`). Each was checked again with the pack on core's main; [AUDIT.md](./AUDIT.md) says how under its id, and git history keeps the entries as they were.

|---|---|---|---|---|
| T25-12 | 3.2.1–3.2.4 | contrast-minimum variant | Every failure of `rgaa-contrast-minimum` names all four 3.2 tests, though its size and weight put it under one: 3.2.1 regular text under 24px, 3.2.2 bold under 18.5px, 3.2.3 regular from 24px, 3.2.4 bold from 18.5px. The failures share one reason code, so the rule map can't split them, and a variant is configuration only, with no code to read the finding's stable `typography.isBold`, `typography.isLargeText` and `typography.fontSizePx`. | A way for a standard to name the requirement per finding: a per-occurrence hook on a variant, or a rule-map row that files findings by a typography field as `reasonCodes` does by code. |
| T12-08 | 13.1, 13.3, 13.9, 12.6, 12.7 | composite rollup | An RGAA criterion rolls up `notApplicable` (or `pass`) when its rules are all `notApplicable` (or pass), though some of its tests have no rule: 13.1 reads notApplicable on a page with a script redirect. Core now rolls a WCAG criterion up as `cantTell` (`composite.rollup.cantTell.partialCoverage`) in that case, and a standard's rollup only when it restates WCAG criteria one for one (`applicability: 'wcag'`), which RGAA's criteria do not. | A field on a standard's rollup naming the requirements no rule covers (or `complete: false`), read like `COMPLETE_APPLICABILITY_SCS`, which the pack would fill from `rgaaComposites()`. |
