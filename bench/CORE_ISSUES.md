# Issues that belong to core

Issues found while checking the pack against RGAA 4.1.2 whose cause is in core, so the pack cannot settle them through its map or its own rules. They are collected here to be reviewed together, and are not fixed in core from this branch.

The pack builds against core's main branch (after 1.13.1), which carries the fixes for every other issue listed here before: C1 to C10, T12-08, T1-04, T1-11, T13-02, T13-05, T13-08, T25-13 to T25-16, T67-07, T89-03, T89-04, T89-09, T89-10 and T12-11 are fixed in core or settled by the pack with what core now gives it (reason codes, the contrast settings, `animationsAtScanStart`, `styleSheetTexts`, `partial`). Each was checked again with the pack on core's main; [AUDIT.md](./AUDIT.md) says how under its id, and git history keeps the entries as they were.
