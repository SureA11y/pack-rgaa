# @surea11y/pack-rgaa

RGAA 4.1.2, the French accessibility standard, as a pack for [`@surea11y/core`](https://github.com/SureA11y/core): its criteria and tests, the RGAA tests each of core's rules checks, one result per criterion, the `rgaa-4.1.2` profile, and the rules RGAA requires beyond WCAG.

Not released yet: the pack is being prepared, and comes with `@surea11y/core` 1.11.
